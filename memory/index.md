# Project Memory

## Core
PSMS - Petrol Station Management System. React + Lovable Cloud.
Industrial theme: navy primary, amber/orange accent. JetBrains Mono for numbers, Inter for body.
KES currency. Roles: admin, manager, attendant. M-Pesa integration per branch.
Multi-branch architecture: each branch has own fuel types, M-Pesa credentials, and attendants.
